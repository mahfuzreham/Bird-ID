# Bird ID V2.0.0

## Highlights

- Guest-session scan history
- Main-page history navigation

- VERSION and CHANGELOG files

Guest credits and history remain tied to the browser session. Account recovery is planned for a future release.

The roadmap includes a larger bird database, regional suggestions, habitat information, bird sound identification, optional accounts, administration tools, multilingual results, community corrections, expert review, and improved juvenile recognition.
